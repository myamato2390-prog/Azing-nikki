## A. 先に直したほうがよいもの（不具合）

### A-1. 他のアプリのオフライン用ファイルを消してしまう【いちばん大事】
- **何が起きるか**：アユ日記が新しい版に入れ替わるたびに、同じ `myamato2390-prog.github.io` にある**お豆日記のオフライン用ファイルまで消してしまう**。消された後に電波のない堤防でお豆日記を開くと、アプリが開けない。記録（IndexedDB）は消えない。
- **原因**：`sw.js` の `activate` で、自分の版以外のキャッシュを**全部**消している。キャッシュは同じサイト（github.io）の中で共通。
  ```js
  keys.filter((k) => k !== VERSION)   // ← 他のアプリのキャッシュも消える
  ```
- **直し方**：自分の名前で始まるキャッシュだけを消す。お豆日記はもう直してある（`sw.js` 参照）。
  ```js
  const PREFIX = 'ayu-nikki-v';
  const VERSION = `${PREFIX}1.3.1`;
  keys.filter((k) => k.startsWith(PREFIX) && k !== VERSION)
  ```
- テスト版（B-2）を入れるなら、テスト版は `ayu-nikki-test-v` にする。

### A-2. 長いメモがカードで見えない
- **何が起きるか**：カードのメモは4行で切っているが、5行目の上半分が切れて見え、続きがあることも分かりにくい。タップで広げても、カードの中を上下にスクロールしないと読めず、横スワイプとぶつかる。
- **直し方**（お豆日記 v0.3.3）：
  - カードは3行できれいに切る。余白を外側の箱に付け、切る行の下に次の行がのぞかないようにする。
  - 3行に収まらないときだけ「▼ 続きを読む」を出す。
  - メモを押すと、下から出る画面にメモ全体を大きく出す。スクロールして最後まで読める。
- 参考：お豆日記の `js/app.js` の `showMemo`、`cardHtml` のメモ部分、`css/style.css` の `.memo-text` `.memo-more` `.memo-overlay` `.memo-sheet`。

### A-3. 保存に失敗しても「保存済み」と出る
- **直し方**：`db.put` が失敗したら、「⚠ 保存できませんでした」と出して、もう一度保存できる状態に戻す。トーストで「スマホの空き容量を確認してください」と出す。お豆日記の `viewEdit` の `save()` を参照。

### A-4. バックアップの読み込みが「上書き」
- **今のアユ日記**：「同じ記録は上書きされます」。古いバックアップを読み込むと、新しく直した記録が古いもので上書きされる。
- **直し方**（お豆日記 v0.1〜）：
  - 読み込みは**足すだけ**にする。同じ id の記録は `updatedAt` が新しい方を残す。今ある記録は消さない。
  - 別のアプリのバックアップ（`app: 'aji-nikki'`）は、やさしい言葉で断る。
  - 仲間のカードのファイル（`type: 'cards'`）も、バックアップと取り違えないよう断る。

## B. そのまま移せるもの（便利）

### B-1. 記録を1件ずつ消す＋元に戻す（お豆日記 v0.3.1）
- 設定に「記録を1件ずつ消す」を置く。ふだんは閉じてあり、新しい順に並ぶ。
- 「消す…」→「本当に消す」（赤）の2段階。何もしなければ5秒で元の表示に戻る。
- 消した直後の約8秒は、トーストに「元に戻す」ボタンを出す。入力画面の「この釣行を削除」も同じにする。
- 参考：お豆日記の `toast(msg, action)`、`deleteTrips(ids, after)`、設定の `renderDelList`。アユ日記には「両方の日」がないので、`pairId` の処理は要らない。

### B-2. テスト版で確かめてから本番に出す（お豆日記 v0.3.2）
- **URL**：本番は `…/Ayu-Nikki/`（main）、テスト版は `…/Ayu-Nikki/preview/`（最後に push した作業ブランチ）。
- **記録を分ける**：テスト版は保存場所の名前を `ayu-nikki-test` に変え、本番の記録に触れない（`js/db.js` の `IS_TEST`）。
- **キャッシュも分ける**：テスト版は `ayu-nikki-test-v…`（A-1 とセット）。
- **見分ける**：テスト版の画面の上に、赤い「テスト版」の帯を出す。
- **公開**：GitHub Actions（お豆日記の `.github/workflows/pages.yml` をそのまま使える）。
  - GitHub Pages は初期設定で main からしか公開できない。作業ブランチを push したときは「main から公開し直して」と頼むだけ（relay）にして、公開はいつも main で行う。
  - 作者の作業（1回だけ）：Ayu-Nikki の Settings → Pages の Source を「GitHub Actions」にする。**workflow を main に入れてから**切り替える。
- **注意**：公開が GitHub 側の一時的な不具合で失敗したとき、同じ回を「やり直し（re-run）」すると、公開用のファイルが2つになってまた失敗する。新しい回として動かし直す（workflow_dispatch）。

### B-3. 設定に「あなたの名前」（B-4 を入れるなら）
- 入れるたびに保存する。未入力なら「まだ名前が入っていません」と出す。

## C. 相談してから移すもの

### C-1. 仲間とカードのやりとり（お豆日記 v0.4〜v0.6）
- **何ができるか**：自分のカードを LINE で仲間に送る。もらったカードは「🤝 ◯◯さんのカード」として入り、見るだけ（直せない）。まとめ・作戦ボード・ポイント成績に入れるかを、全体と仲間ごとに選べる。自己ベストと🏆は自分のカードだけで決める。
- **今の送り方（v0.6）**：短いリンク。
  - カードを Firebase の Firestore に置き、リンクには12文字の番号だけを入れる。例：`…/?openExternalBrowser=1#k=7SHB2SBLUG45`
  - 受け取った人は、リンクを押すだけ。保険は「メッセージを長押し→コピー→貼り付けて読み込む」の1つ。
- **保管場所はお豆日記と同じものを使える**
  - プロジェクト `omame-nikki`、データベース名 `omame-nikki`、コレクション `cards`。
  - 番号はランダムなので、アユ日記のカードと混ざらない。
  - カードの中の `app: 'ayu-nikki'` で、相手のアプリを見分けて断る。
  - ルールは「番号を知っている人だけ読める、置くだけ（書き換え・削除・一覧は不可）、項目は `d` と `exp` だけ」。そのまま使える。
- **ここまでに分かったこと（同じ失敗をしないために）**
  - LINE は、文とファイルを一緒に共有されると**文だけ送ってファイルを落とす**。文字のファイル（.txt）は、**ファイルではなく文章として送ってしまう**。→ ファイルで送るのはやめた。
  - LINE の「転送」は LINE の中のトークに送る機能で、ほかのアプリは出てこない。→ 共有の送り先（share_target）もやめた。
  - カードを全部入れた長いリンク（1枚で約1,200文字）は、**Google に危険なサイトと判定された**。→ 保管場所に置いて短いリンクにした。
  - 道が増えると使う人が迷う。送る道・受け取る道は1本ずつにする（作者の希望）。
  - Firestore のデータベースは、作成時に名前が `(default)` 以外になることがある。REST の URL に合わせる（`js/config.js` の `databaseId`）。
- **相談すること**：アユ日記で仲間とカードをやりとりしたいか。分析に入れるときの項目（河川・水位・ポイントなど）をどう合わせるか。
- 参考：お豆日記の `js/cards.js`（`makeCardPack` `importCardPack` `analysisTrips` `uploadPack` `downloadPack` `shareIdIn`）、`js/config.js`、`tests/cards.test.mjs`、SPEC.md の 6-2。

### C-2. 暗い画面（夜向け）と明るい画面の切り替え
- アユは日中の釣りなので、要るかどうかは相談。
- 入れるなら、お豆日記の `css/style.css` の `:root` と `:root[data-theme="light"]` の色の分け方と、設定の切り替えが参考になる。

### 移さないもの
- 潮の自動計算・満潮干潮：海の釣り用。川には要らない。
- 夜釣り向けの時間帯（天気・風を開始〜終了の時間で集める、日付またぎ）：アユは日中なので、今の6時・日中の集め方で足りる。
- タチウオの項目（F表記・テンヤ・餌）、釣り物の切り替え・「両方」の日。

## D. 将来1つのアプリにまとめるための約束

お豆日記はこの形で保存している（お豆日記の SPEC.md 5-2）。アユ日記も、今のうちに合わせておくと統合が楽になる。

| 項目 | お豆日記 | アユ日記でしておくとよいこと |
|---|---|---|
| 釣りの種類 | 記録ごとに `kind: 'aji' \| 'tachiuo'` | `kind: 'ayu'` を付ける（`normalizeTrip` で、ないときは `'ayu'`） |
| 共通の項目 | 日付・場所（`river`）・時刻・天気・朝の気温・最高気温・水温・匹数・最大サイズ・バラシ・ひとこと・メモ・写真・移動・時合 | 名前と形を変えない（アユ日記が元） |
| 釣り物ごとの項目 | `trip.aji` / `trip.tachiuo` | いずれ水位・垢・仕掛けなどを `trip.ayu` にまとめる（今すぐでなくてよい） |
| 海の状況 | `trip.sea`（側・潮・風・常夜灯） | なし |
| 仲間のカード | `trip.shared = { from, originId, receivedAt, use }` | C-1 を入れるなら同じ形 |
| バックアップ | `{ app: 'aji-nikki', version: 1, exportedAt, trips, presets, places }` | `{ app: 'ayu-nikki', … }` のまま。統合時は両方読めるようにする |
